# 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/java-dsa.git
```

### Navigate to the project

```bash
cd java-dsa
```

### Compile a Java file

```bash
javac FileName.java
```

### Run the program

```bash
java FileName
```
